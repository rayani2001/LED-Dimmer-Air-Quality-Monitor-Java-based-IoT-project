# Java Application — LED Dimmer + Air Quality Monitor

## How to Run

1. Open IntelliJ IDEA
2. Open this `java-app` folder as a project
3. Go to **File → Project Structure → Libraries → + → From Maven**
4. Search: `com.fazecast:jSerialComm` → select latest → OK
5. Run `src/leddimmer/MainWindow.java`
6. Select your COM port → Click Connect

## Requirements
- Java 11 or higher
- IntelliJ IDEA
- jSerialComm library
- Arduino connected via USB
