LED Dimmer +
Air Quality Monitor

A Java Swing GUI communicates with Arduino Uno via USB Serial to control
LED brightness and monitor real-time air quality with an MQ gas sensor.

👤 Rayani Minoli W.D. Fernando 🔧 Arduino Uno ☕ Java Swing 💨 MQ Gas Sensor
01 — Overview

What does this project do?

A physical Arduino circuit connected to a Java desktop app. Control an LED's brightness from your computer and monitor air quality in real-time — all through a USB cable.

💡
LED Brightness Control
A smooth slider controls a red LED from 0–100% using Arduino PWM on Pin 9. Includes OFF and FULL shortcut buttons with live glowing preview.
🌬️
Air Quality Monitoring
MQ gas sensor reads analog values (0–1023) every 2 seconds. The GUI shows live readings with a color-coded progress bar and alert system.
🔌
Serial Communication
Java and Arduino talk over USB at 9600 baud using a simple text protocol. Commands like BRIGHT:75 and GAS:487 keep it readable and easy to debug.
🚨
Gas Alert System
When gas exceeds 500, the bar turns red and shows "HIGH LEVEL DETECTED". Levels 200–499 show orange as a warning. Below 200 shows green — clean air.

07 — Reflection

What I Learned

A short reflection on the development process, challenges, and results.

The most challenging part of this project was establishing stable serial communication between Java and Arduino. Understanding how to parse incoming serial data character by character using a line buffer was a key learning moment.

Working with PWM to control LED brightness taught me how analog-like output can be achieved on a digital microcontroller. Mapping the 0–100% slider value to 0–255 PWM range using Arduino's map() function was a practical and satisfying solution.

What works successfully in the final version: the LED responds instantly to slider changes, the gas sensor sends reliable readings every 2 seconds, and the Java GUI updates the color-coded progress bar in real time. The system demonstrates clear Java ↔ Arduino integration.
