LED Dimmer +
Air Quality Monitor

A Java Swing GUI communicates with Arduino Uno via USB Serial to control
LED brightness and monitor real-time air quality with an MQ gas sensor.

👤 Rayani Minoli W.D. Fernando 🔧 Arduino Uno ☕ Java Swing 💨 MQ Gas Sensor
01 — Overview

What does this project do?

A physical Arduino circuit connected to a Java desktop app — control an LED's brightness from your computer and monitor air quality in real-time, all through a USB cable.

💡
LED Brightness Control
A smooth slider controls a red LED from 0–100% using Arduino PWM on Pin 9. Includes OFF and FULL shortcut buttons.
🌬️
Air Quality Monitoring
MQ gas sensor reads analog values (0–1023) every 2 seconds. The GUI shows live readings with a color-coded alert system.
🔌
Serial Communication
Java and Arduino talk over USB at 9600 baud using a simple text protocol. Commands like BRIGHT:75 and GAS:487 keep it readable.
🚨
Gas Alert System
When gas exceeds 500, the bar turns red and shows "HIGH LEVEL DETECTED". Levels 200–499 show orange as a warning.

04 — Software

Arduino & Java Code

Two software components: an Arduino sketch running on-device, and a Java Swing desktop GUI on your PC.

🔧
Arduino Sketch (sketch.ino)
• Sends READY on boot
• BRIGHT:n → sets LED via analogWrite()
• STATUS → replies GAS:n
• Auto-sends gas every 2 seconds
☕
Java Swing GUI
• MainWindow.java — all GUI panels
• SerialManager.java — jSerialComm port handler
• Slider + OFF/FULL + gas bar + serial log
Arduino Sketch (sketch.ino)
// LED Dimmer + Air Quality Monitor // Rayani Minoli W.D. Fernando — Riga Nordic University const int LED_PIN = 9; const int GAS_PIN = A0; unsigned long lastGasTime = 0; String inputBuffer = ""; void setup() { Serial.begin(9600); pinMode(LED_PIN, OUTPUT); analogWrite(LED_PIN, 0); Serial.println("READY"); } void loop() { if (millis() - lastGasTime >= 2000) { Serial.print("GAS:"); Serial.println(analogRead(GAS_PIN)); lastGasTime = millis(); } while (Serial.available()) { char c = (char)Serial.read(); if (c == '\n') { processCmd(inputBuffer); inputBuffer = ""; } else inputBuffer += c; } } void processCmd(String cmd) { cmd.trim(); if (cmd.startsWith("BRIGHT:")) { int pct = constrain(cmd.substring(7).toInt(), 0, 100); analogWrite(LED_PIN, map(pct, 0, 100, 0, 255)); Serial.print("OK:"); Serial.println(pct); } else if (cmd == "STATUS") { Serial.print("GAS:"); Serial.println(analogRead(GAS_PIN)); } }
